# 🚗 Car Game

A simple browser-based car racing game built with **HTML, CSS and JavaScript**.

### 🎮 Live Demo

🔗 **[Play Car Game](https://rupesshhh-coder.github.io/car-game/)**

### ✨ Features

* 🎮 Arrow-key car movement
* 🚘 Enemy cars
* 💥 Collision detection
* 🏆 Score system
* ⚡ Increasing game speed
* 🔄 Restart after Game Over

### 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

### ▶️ Run Locally

Open `index.html` in any modern web browser.
